# 🤖 AI Resume Builder

**AI Resume Builder** is a full-stack web application that helps users create professional resumes through an intuitive, guided workflow. The platform combines modern web technologies with AI-powered content assistance, enabling users to generate polished resume sections, organize their information effectively, and export job-ready resumes with minimal effort.

Many students and job seekers struggle with resume structure, content quality, and presentation. This project addresses that challenge by providing a streamlined resume-building experience where users can manage their profiles, generate professional content, customize resume sections, and download their final resume in a clean, professional format.

### Key Features

* **Secure Authentication** using JWT-based login and registration
* **AI-Powered Content Assistance** for summaries, skills, projects, and experience descriptions
* **Dynamic Resume Builder** with editable sections
* **Real-Time Resume Preview**
* **Professional Resume Templates**
* **PDF Export Functionality**
* **Responsive Design** for desktop and mobile devices
* **Resume Management Dashboard** to create, edit, and maintain resumes

### Tech Stack

**Frontend:** React.js · Tailwind CSS · React Router · Axios

**Backend:** Node.js · Express.js · JWT Authentication

**Database:** MongoDB Atlas via Mongoose

**AI Integration:** Gemini API / OpenAI API

### User Workflow

1. Register or log in to the platform
2. Create and manage your profile
3. Add education, skills, projects, certifications, and experience
4. Use AI assistance to improve resume content
5. Preview changes in real time
6. Select a preferred resume layout
7. Export the final resume as a PDF

### Project Goal

The goal of this project is to simplify resume creation by providing an intelligent, user-friendly platform that helps individuals present their qualifications professionally while reducing the time and effort required to build a high-quality resume.
